# Arch-Inspired Portfolio Interface

This repository is an earlier portfolio experiment that presents personal content through a desktop interface inspired by Arch Linux environments.

## Canonical portfolio

Active portfolio development is maintained in [jeevanu345/portfolio-site](https://github.com/jeevanu345/portfolio-site).

This repository is retained as a design experiment and is archived. It should not be interpreted as an operating-system implementation or as an “Arch Linux 20.04” release.

## Technology

- React
- Vite
- Tailwind CSS
- Node-based local server

## Local setup

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```
